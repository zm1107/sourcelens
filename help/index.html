源鉴 SourceLens 用户手册

本文对应 4.0 版本，内容以发布的软件为准；功能口径变更时随版本一并更新。 English manual: User Guide (English)

一、界面总览

主界面两个页签：比对分析（日常主流程）与 OCR 转换（独立转换工具）。菜单栏：

  • 文件：添加文件 / 添加文件夹、导出报告、退出；
  • 参数指标：分析参数…（风险阈值 / 并行核数 / 启用文档指纹，含指标插件入口）、指标插件…、启用文档指纹（勾选）；
  • 设置：管理错别字词典（全部生效词条，支持增删改与空格分隔 CSV 导入导出）、比对时查询本地历史库（勾选）、比对完成自动入库（勾选）、云端库配置、本地数据管理；
  • 帮助：使用说明（本文件）、关于（版本、官网 https://sourcelens.weibaba.fun、反馈邮箱 feedback@weibaba.fun）。

主界面布局：文件操作 + 项目名称（* 必填，红色提示）+「分析参数…」按钮 + 配置摘要（阈值 / 并行 / 指纹 / 词典条数）+「错别字复核…」按钮 + 文件列表 + 比对按钮 + 六个结果页签。

二、比对分析流程

  1. 添加文件：支持多选；文件列表列为 文件名 / 大小 / 类型 / 投标公司 / 状态。Del 键或右键菜单可移除选定行；表头点击可排序。载入后会自动智能解析投标公司（仅填空不覆盖）：自动填入的单元格以蓝色显示并悬停提示「供参考，需用户确认」，双击核对或修改后转正常色；未能识别的留空可手动填写。
  2. 维护投标公司（历史库功能相关）：点击「智能解析公司名」随时重新识别（同样仅填空），双击「投标公司」单元格可手工修改；上方「项目名称」整批填写——必填项：为空时标签以警示色显示「项目名称（* 必填）」且输入框浅黄底，填写后恢复；未填写时无法开始比对。
  3. 设置参数：
    • 高风险阈值 / 中风险阈值（默认 60 / 30）：修改后立即重判分组，无需重新分析；
    • 并行核数：OCR 并行度；
    • 文档指纹总开关：关闭后跳过指纹通道（指纹证据不再计入风险积分）。
  4. 选择指标插件：点击参数区「指标插件…」按钮打开设置窗口——每项指标均可勾选启停并自定义权重分值（0.00–1.00）；所有启用指标的权重合计必须恰为 1.00（100%）——不足或超出都会红色强提醒且无法保存。指标权重用于「文风相似」证据项的风格通道聚合；指纹指标注明证据级别说明；标注「（耗时）」或「（默认关闭）」的指标（噪声相关检测、渲染断行比对）按需开启——渲染断行比对需本机 Office。恢复默认可一键还原全部启停与权重。保存后下次比对生效。
评分体系（证据累加制）：总分 = 各证据项累加的风险积分（0–100）——铁证级指纹 +55（含元数据特征值吻合：双方作者/最后修改者/公司为相同的真实专属值，如同名真实姓名——可伪造字段却未清除且一致，近乎自证同源；而匹配不上或为空不降低风险）、强证据指纹命中率 ≥85%/≥70%/≥50% 记 +40/+28/+18、人工采信错别字 +12/个、≥50 字完全相同大段 +15/处、文风相似 ≥85%/≥70%/≥50% 记 +12/+8/+4、环境类指纹佐证 +2/类；渲染断行吻合率 <35%（版式实证发散）为消除项：总分 −25 且封顶 25。累计分 ≥ 高风险阈值（默认 60）→ 高风险，≥ 中风险阈值（默认 30）→ 中风险，否则低风险。每对的证据明细在证据详情页逐项展示。
  1. 开始比对：进度条逐阶段推进（提取 → 指纹 → 切分/模板剔除 → 特征 → 两两比对 → 聚类 → 历史库），文件状态列逐个更新（待分析 → 已提取 → 已提取·指纹完成 → 分析完成）；运行日志带时间戳记录各阶段，供复核归档。
    扫描件识别（两种模式）：默认「快档」——只对连文字层都没有的页做 OCR，带薄文字层（页眉/页码/印章）的扫描页按这层文字参与分析；如需把这类页也整页识别，在「分析参数…」勾选「全量 OCR（深度识别扫描页）」，点「开始比对」时会先弹窗给出本次待识别页数与预计耗时（按 8 线程约 1.25 秒/页估算，可选「本次跳过」只跳这一次）。识别进度按「文档 i/N · OCR：已完成/总页数」逐页推进，日志结束时给出「原生文字页 / OCR 页」页数；结果按文档写入缓存，之后重跑秒级完成（中途取消最多丢当前这一份的 OCR 结果）。扫描页较多时可调高并行线程数。
  2. 错别字人工复核：比对完成后，若生效词典在本轮文档中命中双方共现的错别字，会第一时间弹出复核窗口——匹配范围为每份文档的整篇全文（含公共模板段落中的命中；只在单份文档出现的写法不上榜），每条显示疑似错词、正确写法、「出现文档」、双方文档中的摘录句（错词前后各 5 字，错词以红色粗体标出）与页码（A 页码 / B 页码），供人工识别：
    • 出现文档：该写法命中的文档序号（英文逗号分隔，如「1,3」）；采信后计入评分。列宽固定、内容超出时自动换行；「文档A/B页码」两列同样固定列宽、超出自动换行；句子与判定相关列始终完整显示；
    • 采信：确为错别字——可计分项纳入本次评分（+12/个，同源强信号），不涉及以后批次；
    • 排除：认定为正确表达——不纳入评分，且今后不再判定该词（长期生效）；再点同一键可取消判定；
    • 未处理：默认不纳入本次评分且不影响今后；
    • 批量处理：按住 Ctrl / Shift 多选行后，用窗口底部「批量采信 / 批量排除」一次处理（未多选时两键灰色不可用）；
    • 手动唤起：参数区「错别字复核…」按钮可随时打开复核窗口（不必等比对自动弹出）——列出全部词典命中并预填当前判定，可改判或取消，应用后即时重算；
    • 「应用并重算」即时按判定重算总分、判定与聚类（无需重新分析）；「暂不处理」沿用现评分，下次比对再问。
  3. 查看结果（六个页签）：
    • 围标报价规律（检出报价时显示）：批次结论文字 + 各文档金额柱状图（从低到高，标出差价与差额比例）+ R1–R5 逐规则小图——等差序列（相邻差相对均值）/ 固定比例（比值散点与常见让利比例目标线）/ 同尾数（末 2、3 位数字行）/ 倍数关系（相对最低价的倍数与整数倍刻度）/ 极差率（极差带与阈值带）；红=命中、灰=未命中，图上数值与上方规则结论同源；
    • 聚类分组：疑似同源分组。成组规则与两两矩阵一致——任一对风险积分达到高风险阈值即归入同一组（连通分组），不会出现「矩阵里互相高风险、聚类却孤立」的情况；组行分数为组内全部文档对（两两）风险积分的算术平均（悬停可见组内对明细与成组规则），文档行分数为该文档与组内其他文档的最高对分；
    • 两两匹配矩阵：每对文档的风险积分与风险判定（高风险 / 中风险 / 低风险），颜色越红风险越高；
    • 证据详情：下拉选择文档对（按风险积分降序），头部展示风险积分与证据累加明细，逐插件展示命中证据（共现错别字 / 共现高频用词 / 共现套话，页码全列出不省略）与高相似段落；
    • 文档指纹：全部指纹指标的全量明细表（指标 / 状态 / 级别 / 比对结果），铁证 / 强证 / 佐证三级；「已比对、未发现吻合」以灰色注明；格式不适用 / 无数据 / 开关未开分别注明原因；
    • 历史比对：本批文档按身份码在本地 / 云端历史库的命中明细（历史项目 / 公司 / 文件名 / 时间 / 上报单位）。
  4. 调整阈值：结果出来后改阈值即时重组分组。
  5. 导出报告：HTML 格式，文件名带时间戳前缀（YYYYMMDDHHMMSS_源鉴·同源比对分析报告.html），六章结构（聚类分组 / 矩阵 / 清单 / 证据 / 指纹 / 历史库）。

三、历史数据库

  • 身份码：全文件 SHA-256。文件改名、复制、传输后号码不变；内容修改后号码改变。
  • 本地库：零配置，运行目录 data\history.db；「比对时查询本地库」「比对完成自动入库」默认开启。先查后写：本次入库的记录自下一轮比对起参与命中。
  • 云端库（可选）：设置区启用并填写 PostgreSQL 连接，可分别开启「云端历史比对」「自动上传」；上报单位名称随记录展示。云端仅存档案数据（身份码 / 指纹 / 出现记录），不含文书正文。

四、错别字词典

「设置 → 管理错别字词典」：管理全部生效词条（内置 981 条 + 用户增改），支持双击编辑、添加、删除（内置词条同样可删）与全量 CSV 导入导出——每行「错误写法 正确写法」，空格分隔；导出后修改再导入即可完成删除与方向修正，导入时自动核对方向（疑似颠倒的行会提示确认）。覆盖层持久保存于 %APPDATA%\SourceLens\typos_extra.csv（增改）与 typos_removed.csv（删除），下次启动自动生效。共现错别字是风格通道的重要信号，词典越准结果越可靠。

仅按词典判断：错别字只按词典精确匹配判断（内置词典 981 条 + 用户自定义），4.0 起取消了旧的「4 字长度上限」与「疑似写法」通道（分词误判过高）——词典词条为精确子串匹配，长词条（如「资格审查→资格申查」）同样准确，且匹配容忍词内换行与少量空格（PDF 逐行提取、OCR 常把词切断）。匹配范围为每份文档的整篇全文（公共模板段落中的错别字同样匹配、同样计分）；复核窗口只列出双方共现的写法作为同源信号，只在单份文档出现的错别字不上榜、不计分（每次比对后的运行日志会打印「错别字词典」统计行与共现词表，可据此确认词典是否生效）。发现误报条目直接在词典管理中删除即可。

五、OCR 转换

「OCR 转换」页签：选择 PDF 文件（可多选）→ 输出格式（txt / docx）与输出目录 → 开始转换。扫描件自动 OCR；比对时的扫描页判定同时看「文字是否稀疏」与「是否以整页图片为主」——扫描件常带一层很薄的文字层（页眉/页码/印章，几十字），只按字数判会把它当普通文字页放过、正文读不到，故此类页一律走 OCR（转换结果同样按文件缓存）。

六、结果解读要点

  • 风格分数 ≥80 同人倾向、60–80 存疑、<60 不同人倾向（默认阈值，可校准）；
  • 多通道互证才可靠：风格高分 + 指纹铁证同时出现时结论最强；单一佐证仅作线索；
  • 佐证类证据（元数据、排版等）可修改、伪造，需甄别；元数据缺失不等于不同源；
  • 噪声相关检测为实验性指标：未检出强相关不等于不同源（压缩与二值化会摧毁噪声信息）；
  • RSID 命中可能来自共用模板，需结合模板情况复核；
  • 本工具仅作辅助研判，最终认定请以人工复核原文为准。
