风格、指纹、报价，三维交叉研判

单一角度容易被规避，三个角度同时看向一份标书——每一路都是独立证据，合成分数逐项可解释。

三维综合评分

文档指纹证据、写作风格、报价规律三路信号合成一个综合分，按高 / 中 / 低风险分级提示。

  • 逐项可解释：每一分都对应看得见的证据，不接受「黑箱分数」
  • 阈值可调：风险分级线随你的审查尺度调整，即时重新分组
  • 人机分工：机器把可疑对浮出水面，最终认定始终留给人工复核

围标报价规律分析

自动抽取各标书报价清单金额，识别一组报价之间可疑的规律性特征，条形图直观对比。

  • 一屏看清：报价条形对比，谁和谁「心有灵犀」一眼可辨
  • 计入证据：规律命中进入综合评分，并在证据详情给出对级明细
  • 防误伤：内置多重防护判断，正常报价不会被轻易误判

写作风格画像

像笔迹鉴定——用词、句长、标点、套话、数量表述、词性文风、共现错别字，七项习惯加权合成风格相似度。

  • 共现错别字是最强风格信号——同一处错，暴露同一双手
  • 近千对领域错词词典：只按词典精确匹配，不猜不蒙
  • 两键复核：错别字「采信 / 排除」批量处理，排除的选择持久记住

文档指纹取证

像物证鉴定——14 类独立通道检查「内容之外」的痕迹：元数据、图片、编辑谱系、隐藏内容……

  • 共享实体锁定：电话、邮箱、证件号、账号跨文档雷同直接作为高等级证据
  • 改写难逃：文档结构、近似指纹、图片属性——改了文字也抹不掉
  • 页码定位：每条证据可回原文核对，铁证 / 强证 / 佐证分级标注

五步，从一堆标书到一份取证报告

PDF / DOCX / DOC 混合添加，扫描件自动离线 OCR；同批文档二次分析秒级完成。

1 添加文档 2 份以上标书混合添加；扫描页自动 OCR，全程离线
2 智能解析 从文件名识别投标公司名填入列表，可人工核对修改
3 一键比对 提取文本 → 剔除公共模板 → 风格统计 → 打分 → 聚类 → 指纹比对
4 查看结果 报价规律 / 聚类分组 / 匹配矩阵 / 证据详情 / 指纹明细 / 历史比对
5 导出报告 HTML 取证报告按时间戳命名，证据全部附页码

不是所有证据都一样可靠

源鉴按「被篡改的难度」给证据分级，帮你把注意力放在刀刃上。

铁证级 近乎自证的同源信号——刻意规避也极难抹净，单条即可显著抬升风险等级
强证级 多通道互相印证的实质性证据，构成研判的主要依据
佐证级 环境类旁证，仅供参考——已明确标注「可修改、伪造，需甄别」
诚实条款：所有结论均为辅助研判，最终认定以人工复核原文为准；元数据缺失或被清空不等于不同源；请在合法授权范围内使用（招投标监督、司法取证、内部合规审查等场景）。
