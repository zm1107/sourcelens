## 功能亮点

- **三维综合评分**：文档指纹证据、写作风格、报价规律三路信号合成一个综合分，按高 / 中 / 低风险分级，阈值可调；分数逐项可解释，最终认定留给人工复核
- **围标报价规律分析**：自动抽取报价清单金额，识别一组报价之间可疑的规律性特征，条形图直观对比，命中计入综合评分
- **写作风格画像**：用词、句长、标点、套话、数量表述、词性文风、共现错别字七项特征；近千对领域错词词典精确匹配，「采信 / 排除」两键复核
- **文档指纹取证**：14 类独立通道（元数据、排版、图片、RSID 编辑谱系、隐藏内容、结构树、近似指纹、EXIF、共享实体发现等），逐条附页码定位
- **证据分级与串并**：铁证 / 强证 / 佐证三级可信度；文档身份码（全文件 SHA-256）+ 本地 / 自建云端历史库支持跨案件串并
- **支持格式**：PDF（扫描页自动离线 OCR）/ DOCX / DOC 混合比对；独立 OCR 转换 PDF → TXT / DOCX
