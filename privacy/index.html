源鉴（SourceLens）隐私政策

生效日期：2026 年 9 月 28 日  ·  Effective date: September 28, 2026
中文 English
核心承诺：源鉴完全离线运行：无网络请求、无遥测、无统计、无账号、无 Cookie。 你的文书内容始终留在你自己的电脑上——适配涉密环境。

1. 处理方式：完全离线

源鉴的全部功能（文本提取、扫描件 OCR、风格统计、指纹比对、评分聚类、报告导出）均在本机完成。 应用不包含任何联网代码、遥测上报、统计埋点或账号体系，也不使用 Cookie。

2. 数据存放在哪里

数据位置说明
文档内容与提取结果本机用户数据目录 %APPDATA%\SourceLens\ 与运行目录 data\提取文本、分析中间结果（三级缓存，同批文档二次分析提速）
指纹数据与比对记录同上本机目录（SQLite 本地历史库）文档身份码（全文件 SHA-256）、指纹特征、历史比对记录
取证报告你指定的输出位置导出的 HTML 报告由你自行保管
配置与错别字词典本机配置文件阈值、插件启停、复核排除选择等界面配置

这些数据只存在于你的电脑，不向任何服务器传输。

3. 云端历史库：可选的自建服务

「云端历史库」功能默认关闭，不开即无任何联网行为。该功能面向需要跨机器串并案的团队， 由你自行搭建与部署（部署脚本随应用仓库提供）；启用后仅上传以下档案数据：

  • 文档身份码（全文件 SHA-256）与指纹特征；
  • 出现记录：项目名、投标公司名、时间、上报单位。

永远不上传文书正文；数据库账号仅授予 SELECT / INSERT 权限。

4. 源文件只读

比对过程不修改、不移动、不删除你的标书原文件；所有结果都写入本机数据目录或你指定的输出位置。

5. 卸载与数据残留

卸载应用不会自动删除本机数据目录（含历史库与缓存）。如不再需要这些数据， 请在卸载后手动删除对应目录。

6. 联系我们

如有隐私相关问题，请通过微软商店页面提供的支持渠道联系开发者；也可写信到 feedback@weibaba.fun。

7. 关于本网站

本网站为纯静态 HTML 页面：不含统计分析、行为追踪、Cookie 或任何表单， 不向任何第三方服务器发起请求（页面内的外部链接仅在你主动点击时才会跳转）。 网站不记录、不存储任何访问者信息。

Our core promise: SourceLens runs fully offline: no network requests, no telemetry, no analytics, no accounts, no cookies. Your documents stay on your computer — suitable for classified environments.

1. Processing: Fully Offline

Every SourceLens feature (text extraction, scan OCR, style statistics, fingerprint comparison, scoring & clustering, report export) runs on your machine. The app contains no networking code, telemetry, analytics or account system, and uses no cookies.

2. Where Data Lives

DataLocationNotes
Document text & extraction resultsLocal user data folder %APPDATA%\SourceLens\ and the runtime data\ folderExtracted text, intermediate analysis results (three-level cache for fast re-analysis)
Fingerprints & comparison recordsSame local folders (SQLite history database)Document identity codes (full-file SHA-256), fingerprint profiles, past comparisons
Forensic reportsWherever you choose to exportExported HTML reports are yours to keep
Settings & typo dictionaryLocal configurationThresholds, plugin toggles, review exclusions and other UI settings

This data exists only on your computer and is never sent to any server.

3. Cloud History: Optional, Self-Hosted

The "cloud history" feature is off by default — with it off, the app performs no network activity at all. It is intended for teams that need to link cases across machines and is deployed on infrastructure you control (deployment scripts ship with the app repository). When enabled, it uploads only profile data:

  • Document identity codes (full-file SHA-256) and fingerprint profiles;
  • Occurrence records: project name, bidder company, time, reporting organization.

Document text is never uploaded; the database account receives SELECT / INSERT privileges only.

4. Source Files Are Read-Only

Comparison never modifies, moves or deletes your bid files; all results are written to the local data folders or the output location you specify.

5. Uninstall and Leftover Data

Uninstalling the app does not automatically delete the local data folders (history database and caches included). If you no longer need this data, delete the folders manually after uninstalling.

6. Contact

For privacy questions, reach the developer via the support channel on the Microsoft Store listing, or write to feedback@weibaba.fun.

7. About This Website

This website is a set of purely static HTML pages: no analytics, no behavioral tracking, no cookies, no forms, and no requests to any third-party server (external links open only when you click them). The site records and stores nothing about its visitors.
